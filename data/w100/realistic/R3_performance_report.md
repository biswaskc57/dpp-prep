# TEST REPORT NW-PR-2026-014

## 1. Specimen description
Single-sash inward-opening casement window, laminated pine frame with aluminium cladding.
Glazing: triple glazing 4-16-4-16-4, two low-e coatings, argon filled (90 %), warm-edge spacer.

## 2. Input values

| Quantity | Symbol | Value | Unit |
|---|---|---|---|
| Thermal transmittance of glazing | Ug | 0.5 | W/(m2K) |
| Thermal transmittance of frame | Uf | 1.2 | W/(m2K) |
| Linear thermal transmittance, glazing edge | Psi_g | 0.035 | W/(mK) |
| Visible frame width | bf | 112 | mm |

## 3. Result
For the reference size 1230 x 1480 mm (EN 14351-1, Annex E):
Uw = 1.1 W/(m2K)

For the test specimen size 1000 x 1200 mm the calculated value is Uw = 1.2 W/(m2K) (informative only).

## 4. Validity
The result applies to the product W-100 as described in section 1. This report replaces report NW-PR-2025-031.
